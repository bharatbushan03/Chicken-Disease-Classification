# Security Policy

## Supported Versions

Currently, only the latest version of this project is supported.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please open an issue on GitHub. For sensitive issues, please contact the maintainer directly if contact information is available.

We will acknowledge your report and work to address the issue as soon as possible.
